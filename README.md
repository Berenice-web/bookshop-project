# asm-book-shop
Projet realise dans le cadre du module Developpement Web B1 (ECE 2025).

Ce site permet aux utilisateurs de :
- consulter un catalogue de livres
- creer un compte
- se connecter a leur espace membre
- acheter ou emprunter des livres
- et permet a un administrateur de gerer les utilisateurs et les livres

---

## Fonctionnalites

Utilisateur :
- Connexion / Inscription
- Acces a un espace personnel
- Catalogue de livres filtrable
- Ajouter au panier
- Achat des livres

Administrateur :
- Ajouter / modifier / supprimer un livre
- Gerer les utilisateurs (supprimer, bloquer)
- Visualiser des statistiques
